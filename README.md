# 📰 News App (Android)

A modern Android application that displays the latest news articles using a public News API.  
The app is built with **Kotlin**, follows **MVVM architecture**, and uses **Clean Architecture principles** for scalability and maintainability.

---

## ✨ Features
- Fetch latest news articles from API using **Retrofit**.
- Show full news details in a separate screen.
- Loading & error handling states.

---

## 🛠️ Tech Stack
- **Kotlin** – Main programming language  
- **Retrofit** – Network requests  
- **Gson** – JSON parsing  
- **Coroutines & Flow** – Asynchronous programming  
- **Glide** – Image loading  
- **Navigation Component** – In-app navigation  
- **Material Components** – Modern UI design
